# 🪙 CryptoCompare

Веб-приложение для сравнения цен на криптовалюту с разных бирж в реальном времени.

---

## 📌 Функции

- 🔎 Поиск криптовалют по символу (BTC, ETH и т.д.)
- 📊 Сравнение цен с разных бирж (Binance, KuCoin и др.)
- 💾 Кэширование цен в Redis (обновление раз в минуту)
- 🗂️ Логирование истории сравнений (аудит)
- 🌐 UI-интерфейс на HTML + JS
- 🐘 PostgreSQL база данных
- 🔌 REST API

---

## ⚙️ Технологии

- Go (Golang)
- PostgreSQL
- Redis
- REST API
- Docker (опциональ
